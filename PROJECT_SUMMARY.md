## 🚀 How to Use

### View the Page:
1. Open `src/index.html` in your web browser
2. The page is fully responsive and works on all devices

### Modify Content:
1. Edit `src/index.html` with any text/content changes
2. The Tailwind CSS watcher automatically compiles changes
3. Refresh your browser to see updates

### Build CSS:
```bash
npx tailwindcss -i ./src/input.css -o ./src/output.css --watch
```
